*V2.0 is the same plan with the moving parts taken out. There is one thing to do now — put one car at one bar door and get the state to count — and everything else waits behind a gate that says exactly when it opens. Every line: what, why, cost, done when. The sources behind every number are on their own page, `V1.0 SOURCES`, so this one stays short. The page for Andrea is `V1.1 ANDREA`.*
