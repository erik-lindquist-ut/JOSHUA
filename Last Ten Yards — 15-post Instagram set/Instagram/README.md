# Last Ten Yards — Instagram posts

15 posts. Post 1 is Kristin's. Every post carries #LastTenYards first, then the whole Tesla + SpaceX line.

- Odd slides: real photo, headline, one line.
- Even slides: graphic-novel panel (ink lines, posterized, one accent colorway per post) + "Joshua says: Think, with compassion, about X. Do it differently — with Y, or with Z."
- Faces in crowds are blurred. Every photo is free to use (CC0, public domain, or CC BY / BY-SA) and credited on the slide and in the caption.

| File | What |
|---|---|
| `posts.html` | Open to see all 15 posts; each caption has a Copy button |
| `posts.js` | The posts, tags, and captions (data) |
| `render.js` · `styles.css` | How the slides look |
| `posts.test.js` | 140 specs — `node --test` |
