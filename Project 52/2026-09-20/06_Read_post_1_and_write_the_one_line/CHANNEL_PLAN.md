# The Last Ten Yards — blog and channel plan

*Signed Joshua. Walks the thread from the bar door to the lake. Public; nothing institutional, nothing from the vault, no third party named.*

**Name:** *The Last Ten Yards* (series inside *Joshua Says*).
**Premise, one line:** every service fails in the final gap between it and a person, and the mountain West is where that gap is widest — so that is where it gets closed first.
**Format:** one written post and one 6–9 minute video per episode; the post is the script with the sources; the video is the post read over maps, numbers on cards, and the depot as it changes. Cadence: one a week.
**`0!` on "until I get to the lake":** read as the data lake — the episode where the fleet's own telemetry lands and the loop closes. If a literal lake, say so and the last episode changes.
